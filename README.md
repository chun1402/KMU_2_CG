# KMU_2_CG

**Computer Graphics Project**

계명대학교 컴퓨터 그래픽스 수업에서 진행한 프로젝트입니다.  
컴퓨터 그래픽스의 기본 개념과 렌더링 기술을 학습하고, 이를 실제 프로젝트에 적용하는 것을 목표로 합니다.
